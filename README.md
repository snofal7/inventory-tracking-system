# Inventory Tracking System

This is a Java-based Inventory Tracking System developed as part of a Data Structures project.

## Features
- Add, update, and delete products
- Track inventory using HashMap
- Process customer orders using a Queue
- Store fulfilled orders in an ArrayList
- Low stock alerts

## Technologies
- Java
- Data Structures (HashMap, Queue, ArrayList)

## How to Run
1. Download the project files
2. Open in any Java IDE (IntelliJ / Eclipse)
3. Run the main class

## Project Structure
- Main.java
- Inventory.java
- Order.java

## Description
This project simulates how a retail store manages inventory and processes orders using core data structures.
